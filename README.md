
## Обработка ошибок

Приложение использует пользовательские исключения для обработки ошибок операций.

### Команда buy

- `CurrencyNotFoundError` - указана неподдерживаемая валюта
- `InsufficientFundsError` - недостаточно USD для покупки
- `ValueError` - некорректная сумма или недопустимая операция

### Команда sell

- `CurrencyNotFoundError` - указана неподдерживаемая валюта
- `InsufficientFundsError` - кошелёк отсутствует или недостаточно средств
- `ValueError` - некорректная сумма или недопустимая операция

### Команда get-rate

- `CurrencyNotFoundError` - неизвестный код валюты
- `ApiRequestError` - не удалось получить или обновить курс
- `TypeError` - некорректный тип кода валюты

При ошибке внешнего источника приложение предлагает повторить запрос позже или проверить подключение к сети.

## Логирование

Операции покупки и продажи автоматически записываются в `logs/actions.log`.

Журнал содержит время операции, тип действия, пользователя, валюту, сумму, курс и результат выполнения.

Поддерживаются уровни логирования INFO и DEBUG. Для ограничения размера файлов используется ротация логов.

## Конфигурация

Настройки приложения находятся в секции `[tool.valutatrade]` файла `pyproject.toml`.

Основные параметры:

- `data_dir` - директория хранения JSON
- `rates_ttl_seconds` - время актуальности кэша курсов
- `default_base_currency` - базовая валюта
- `log_file` - путь к журналу
- `log_level` - уровень логирования
- `log_format` - выбранный формат логов

В текущей версии используется учебный источник курсов. Подключение реального API предусмотрено на следующем этапе проекта.
