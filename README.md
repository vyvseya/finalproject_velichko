# ValutaTrade Hub

Консольное учебное приложение на Python для регистрации пользователей, управления виртуальными валютными кошельками и симуляции покупки и продажи валют по курсам из локального кэша.

Актуальные курсы получаются из двух внешних API:
- **CoinGecko** - криптовалюты BTC, ETH, SOL
- **ExchangeRate-API** - фиатные валюты EUR, GBP, RUB

## Установка и запуск

Для работы необходимы Python 3.12 или новее и менеджер пакетов `uv`.

В корневой директории проекта выполните:

```powershell
uv sync
uv run python main.py
```

Программа работает в интерактивном режиме: команды вводятся после приглашения `>`.

Команда `help` показывает справку, а `exit` завершает работу.

## Настройка API

Для получения фиатных курсов необходимо зарегистрироваться на [ExchangeRate-API](https://www.exchangerate-api.com/) и получить API-ключ.

Ключ считывается из переменной окружения `EXCHANGERATE_API_KEY` и не хранится в исходном коде.

Пример настройки в PowerShell:

```powershell
$secureKey = Read-Host "Введите API-ключ" -AsSecureString
$env:EXCHANGERATE_API_KEY = [System.Net.NetworkCredential]::new("", $secureKey).Password
Remove-Variable secureKey
```

Переменная действует в пределах текущего сеанса PowerShell.

Для CoinGecko поддерживается публичный доступ без API-ключа. При необходимости можно использовать необязательную переменную `COINGECKO_API_KEY`.

## Команды CLI

| Команда | Назначение |
| --- | --- |
| `register --username <имя> --password <пароль>` | Регистрация пользователя |
| `login --username <имя> --password <пароль>` | Авторизация пользователя |
| `deposit --amount <сумма>` | Пополнение виртуального USD-баланса |
| `show-portfolio [--base <валюта>]` | Просмотр балансов и стоимости портфеля |
| `buy --currency <валюта> --amount <сумма>` | Покупка валюты за USD |
| `sell --currency <валюта> --amount <сумма>` | Продажа валюты с зачислением USD |
| `get-rate --from <валюта> --to <валюта>` | Получение курса из локального кэша |
| `update-rates [--source coingecko\|exchangerate]` | Обновление курсов из API |
| `show-rates [--currency <код>] [--top <число>] [--base <код>]` | Просмотр сохранённых курсов с фильтрацией |
| `help` | Список доступных команд |
| `exit` | Выход из приложения |

Поддерживаемые валюты: `USD`, `EUR`, `GBP`, `RUB`, `BTC`, `ETH`, `SOL`.

Параметр `--amount` означает количество единиц покупаемой или продаваемой валюты.

При регистрации создаётся пустой портфель. Для начала торговли авторизованный пользователь может пополнить виртуальный USD-баланс командой `deposit --amount 10000`. После этого средства можно использовать для покупки валют. Все операции являются учебными и не связаны с реальными деньгами.

Перед запросом курсов и выполнением сделок необходимо загрузить данные командой `update-rates`.

Команды `get-rate`, `buy`, `sell` и оценка портфеля используют локальные курсы и не отправляют запросы к внешним API напрямую.

Пример использования:

```text
> register --username alice --password 1234
> login --username alice --password 1234
> deposit --amount 10000
> update-rates
> buy --currency BTC --amount 0.01
> show-portfolio
```

## Parser Service

Parser Service отвечает за получение и обновление валютных курсов.

Он использует два источника:
- `CoinGeckoClient` - получает курсы криптовалют
- `ExchangeRateApiClient` - получает курсы фиатных валют

Класс `RatesUpdater` объединяет полученные данные и передаёт их в `RatesStorage` для сохранения.

Если один источник временно недоступен, обновление данных из другого источника продолжается.

### Ручное обновление

Внутри приложения:

```text
> update-rates
```

Обновление только криптовалют:

```text
> update-rates --source coingecko
```

Обновление только фиатных валют:

```text
> update-rates --source exchangerate
```

### Просмотр курсов

Все сохранённые курсы:

```text
> show-rates
```

Курс определённой валюты:

```text
> show-rates --currency BTC
```

Две самые дорогие криптовалюты по цене за единицу:

```text
> show-rates --top 2
```

Курсы относительно евро:

```text
> show-rates --base EUR
```

Перекрёстный курс Bitcoin к евро:

```text
> get-rate --from BTC --to EUR
```

## Автоматическое обновление

Для автоматического обновления используется `RatesScheduler`.

Запуск из корневой директории проекта:

```powershell
uv run python -m valutatrade_hub.parser_service.scheduler
```

Планировщик выполняет обновление сразу после запуска, а затем повторяет его каждые **3600 секунд (1 час)**.

Остановить работу можно сочетанием `Ctrl + C`.

При временной ошибке API планировщик сообщает о проблеме и продолжает работу.

## Хранение данных

Для хранения информации используются JSON-файлы в директории `data/`.

| Файл | Назначение |
| --- | --- |
| `users.json` | Пользователи, хеши паролей и соль |
| `portfolios.json` | Портфели пользователей и балансы кошельков |
| `rates.json` | Последние актуальные курсы валют |
| `exchange_rates.json` | История изменений валютных курсов |

Файлы данных создаются по мере работы приложения и не включаются в Git.

### rates.json

Содержит актуальные значения валютных пар и время последнего обновления.

Пример структуры:

```json
{
  "pairs": {
    "BTC_USD": {
      "rate": 60000.0,
      "updated_at": "2026-11-07T12:00:00Z",
      "source": "CoinGecko"
    }
  },
  "last_refresh": "2026-11-07T12:00:00Z"
}
```

### exchange_rates.json

Хранит историю измерений валютных курсов.

Для каждой записи сохраняются:
- Уникальный идентификатор
- Исходная и целевая валюты
- Значение курса
- Время обновления
- Источник данных
- Поле метаданных

Для предотвращения дублирования используется уникальный идентификатор, составленный из валютной пары и времени измерения.

Сохранение JSON выполняется с использованием временного файла и последующей атомарной замены.

## Актуальность курсов

Core Service получает курсы из локального файла `rates.json`.

Срок действия кэша (TTL) составляет **7200 секунд (2 часа)**.

Если курс отсутствует или устарел, операции, требующие актуального курса, завершаются ошибкой с предложением выполнить `update-rates`.

Планировщик обновляет курсы каждый час, обеспечивая запас времени на случай временной недоступности API.

Команда `show-rates` позволяет просматривать последние сохранённые значения с указанием времени обновления.

## Обработка ошибок

В приложении используются пользовательские исключения для обработки ошибок.

### CurrencyNotFoundError

Возникает при обращении к неподдерживаемой валюте.

### InsufficientFundsError

Возникает при недостаточном балансе для покупки или продажи валюты.

### ApiRequestError

Используется при ошибках обращения к внешним API, а также при отсутствии или устаревании необходимых курсов.

### ValueError и TypeError

Используются для проверки корректности типов данных, сумм операций и аргументов команд.

Ошибки обрабатываются в консольном интерфейсе, поэтому пользователь получает понятное сообщение вместо необработанного исключения.

## Логирование

Приложение использует систему логирования с записью действий в файл:

```text
logs/actions.log
```

Для операций покупки и продажи фиксируются тип операции, пользователь, валюта, сумма, курс и результат.

Parser Service и Scheduler также записывают сообщения об обновлениях и возникающих ошибках в общий журнал.

Для ограничения размера журналов используется ротация файлов.

## Конфигурация

Основные параметры приложения находятся в разделе `[tool.valutatrade]` файла `pyproject.toml`.

| Параметр | Назначение |
| --- | --- |
| `data_dir` | Директория хранения данных |
| `users_file` | Файл пользователей |
| `portfolios_file` | Файл портфелей |
| `rates_file` | Файл текущих курсов |
| `rates_ttl_seconds` | Срок актуальности курсов |
| `default_base_currency` | Базовая валюта |
| `log_file` | Путь к журналу |
| `log_level` | Уровень логирования |
| `log_format` | Формат логов |

Настройки API, отслеживаемые валюты и пути к файлам Parser Service определены в `valutatrade_hub/parser_service/config.py`.
